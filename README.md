# nonlinear_opinion_dynamics

main_bestparameter_fit2510.m is used to calculate the best fitting payoff matrix and the optimal selection intensities for $\alpha = 2,5,10$.

main_bestparameter_fitothers.m is used to obtain the corresponding selection intensities for $\alpha = 1,3,4,6,7,8,9$ based on the previously obtained payoff matrix.

main_network_fitting.m is used to calculate the best fitting payoff matrix and the optimal selection intensities for $\alpha = 2,4,6$ of three networks. Then, we obtain the selection intensities corresponding to other $\alpha$ value for each network, respectively.
